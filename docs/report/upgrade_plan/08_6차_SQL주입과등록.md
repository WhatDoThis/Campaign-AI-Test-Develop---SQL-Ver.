## 6. 구현 상세

### Step 1 — Preflight

1. lockedBy == self (아니면 abort + div)
2. 대상 액티비티 탐지(ShellProbe)
3. 현재 `ai-sql-id`/관련 필드 스냅샷 → `woo` 백업(또는 Option)

### Step 2 — Inject

- Write workflow data: set `ai-sql-id` = selected
- 편집기 가시 필드가 있으면 동일 ID/라벨 반영
- **raw SQL을 script에 쓰지 말 것**

### Step 3 — 2단계 클릭

- 기존 ID 없으면 1클릭 등록
- 있으면 1클릭: 버튼 문구 "덮어쓰려면 다시 클릭", 2클릭: 실행, 타임아웃 복구

### Step 4 — Open 게이트

- 등록 성공 전에는 열기 disabled
- 상시 문구: "등록 전 해당 WKF 편집 창을 닫아주세요"
- 성공 후 열기 enable (PoC-1 경로)

## 7. 구현 불가 (경량 언급 — J-9-5-2)

이미 Explorer에 열린 WKF 창은 클라이언트 메모리의 data XML을 들고 있으며, 저장 시 서버 변경분을 덮어 **역방향 유실**이 난다.  
**구현·폴링·강제 refresh·부분 패치 모두 금지.** DoD/테스트에 넣지 않는다. UI 문구로 "열린 창이 있으면 닫고 등록"만 표시.

## 8. 금지사항

- `confirm`/`alert`
- script 노드에 SQL 본문 삽입
- J-9-5-2 "부분적으로라도" 시도
- Spawn
