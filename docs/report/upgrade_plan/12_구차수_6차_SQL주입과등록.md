## 6. 구현 상세

### Step 1 — Preflight

1. lockedBy == self (아니면 abort + div)
2. 대상 액티비티 탐지(ShellProbe)
3. 현재 편집기 본문 + `ai-sql-id` 스냅샷 → 백업
4. 선택 `ai_sql_id` 행 load → `sql_query` non-empty, status registered

### Step 2 — Inject (무엇을/어디에/왜)

- **무엇을**: (A) 코드편집기 대응 노드/CDATA에 `sql_query` 본문 Write (B) `<ai-sql-id>` = id
- **어디에**: WF `data` XML 내 확정 xpath (HUMAN: 템플릿 액티비티 열어서 필드명 확정 후 상수화)
- **왜**: INJ-8-2 원안 + 런타임 ID 추적
- SOAP 인자 폭주 주의: 본문은 서버 측 queryDef로 읽어 Write — 클라이언트→SOAP로 SQL 전문 왕복 최소화

### Step 3 — 2단계 클릭

- 기존 본문/ID 없으면 1클릭 등록
- 있으면 1클릭: "덮어쓰려면 다시 클릭", 2클릭: 실행, 타임아웃 복구

### Step 4 — Open 게이트

- 등록 성공 전 열기 disabled
- 상시: "등록 전 해당 WKF 편집 창을 닫아주세요"
- 성공 후 열기 enable

## 7. 구현 불가 (경량 언급 — J-9-5-2)

이미 Explorer에 열린 WKF 창은 클라이언트 메모리의 data XML을 들고 있으며, 저장 시 서버 변경분을 덮어 **역방향 유실**이 난다.  
**구현·폴링·강제 refresh·부분 패치 모두 금지.** DoD/테스트에 넣지 않는다. UI 문구로 "열린 창이 있으면 닫고 등록"만 표시.
