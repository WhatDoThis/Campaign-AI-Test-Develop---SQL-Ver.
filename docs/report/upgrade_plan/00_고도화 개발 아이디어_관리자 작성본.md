고도화 개발 가이드를 버전 차수별로 진행할 수 있게 나눠서 제작 필요함.
고도화 필요한 목록은 아래와 같으며 현재 구성에서 로직 확장과 알고리즘 방향에 맞게 차수를 정리하여 나눠줘.
목록의 순서와 차수의 순서는 상관없이 생각나는 대로 작성됨.
또한 아이디어는 내가 생각해서 제공하지만 너가 최적화를 위해 어느정도 수정제안 및 반영에 대한 권한을 줄께.
반드시 어도비 공식문서 및 레퍼런스를 통해 구현 가능한 방향으로 설계 및 제작되어야 함(사용할 수 없는 함수, 기능 등 제한요건 확인 필수).

[화면 설계 고도화 및 기능 정리]
1. 현재 워크플로우 내에 구성되게끔 되어있는데 최종적으로는 네비게이션 하이라키를 통해 tools 에서 AI Studio를 explorer 창으로 열어서 사용하는 것으로 통일될 예정(이미 jssp 창은 연결되어 있으며, 추가기능 필요 2. 확인)

2. AI Studio(testWooAiStudio.jssp) 구성 변경안.
 -> 왼쪽 AI 입력창(답변 상단 70%, 요청 하단 20% 정도 비율 - 지금과 유사)
 -> 오른쪽 목록창(CAMPAIGN 목록 / WKF 목록 / SQL 목록 - 연결되는 파라미터 구조에 따라 변경)
 -> 최상단 제목 바로 아래 5~10% 정도 높이로 정보 표현창 필요.
  예시) 캠페인정보(Label/InternalName) / 워크플로우정보(Label/InternalName) / SQL정보(ID) / 뒤로가기 / 초기화
 -> 입력창 아래 WKF로 이동 -> 생성 또는 선택 후 워크플로우 정보 반영 된 후에는 해당 WKF 창을 explorer에 열 수 있는 버튼 필요

3. 목록창 구성
 -> 캠페인 목록: 예시) AI_Folder1, AI_Folder2 등 특정 폴더명(정책 반영 예정)의 목록을 불러와서 제공. 새 캠페인 생성 없음(생성되면 안됨)
 -> 워크플로우 목록: 새 WKF 생성 필요(디폴트). 선택된 캠페인 폴더 내 WKF목록이 불어와지는 것은 아님. 목록에 대한 정보는 3. 확인 필요.
 -> SQL 목록: WKF에 연결된 SQL 목록. 새 WKF일 경우는 비어있어야 정상.

4. 최초 진입 시 입력창 비활성화 + 안내 문구 -> 오른쪽 목록에서 캠페인 폴더 지정
 -> 특정 Internal Name 의 캠페인 폴더에 해당하는 목록 제공(3. 내용 확인)
 -> 선택 시 해당 캠페인 폴더 정보가 상단에 적용되고 조건 입력창 활성화 및 오른쪽 캠페인 목록이 WKF 목록으로 변경.
 -> 새 WKF 만들고 조건 입력해도 되고, 조건 입력 후 WKF 선택해도 됨(5. 참고).

5. 원하는 조건 입력
 -> 예시) 서울 사는 20대 여자 고객, 학생요금 쓰는 10~13세 고객 등
 -> 동일 조건 혹은 유사도 95% 이상의 조건이 반영된 WKF가 있는 지를 먼저 찾아서 있으면 오른쪽에 목록 제공
 -> 새 WKF 선택 -> 새 WKF 생성 및 WKF 정보 반영되고 해당 조건의 SQL 생성로직(이미 제작되어 있음) 이어서 적용.
 -> 기존 WKF 선택 -> 해당 WKF의 정보 반영 및 연결된 SQL 목록으로 전환

6. old_ver/workflow/template.xml -> WKF 생성 시 해당 템플릿(재사용) 의 컴포넌트들이 새로 생성되는 WKF에 반영되어야 함.

[SQL 생성로직 고도화]
7. SQL Frag 생성 로직 자동화.
 -> 조건 입력 - SQL Frag 조회로직 - 생성 필요시 - 현재는 승인과정 있으나, 자동승인 과정으로 변경 - 중복 문제 승인 로직 제외 - 중복은 별도 관리자 화면을 통해 리스트를 볼 수 있게 하여 frag 삭제만 진행할 수 있게 하는 간단한 방식으로 가는게 좋음.
 -> 사용자는 결국 조건 입력 - 조건 없으면 생성 후 조건에 맞는 SQL 생성 - WKF에 반영 과정이 이어지는 단계에서 간편하게 사용 가능하도록(사용자 편의성이 고객사 RFP 요건에서 매우 중요했음, 관리는 우리의 문제).

 8. SQL 목록에서 선택 후 등록 시 SQL ID만 생성하는 현 로직에서 선택된(또는 생성된) WKF의 템플릿 내 커스텀 Activity 의 SQL 코드 편집기 내 반영까지 바로 적용되어야 함.

 [최종 사용자 여정]
9. AI Studio 열기 - 캠페인 목록에서 캠페인 선택(생성 없음, 캠페인 폴더는 미리 제공되어 있어야 함, Internal name: AI_Folder*) - 캠페인 폴더 정보반영(라벨/인터널네임) 및 WKF 목록창 등장 - WKF 생성 가능 또는 조건 먼저 입력 가능(즉, 1. WKF생성 후 조건입력 또는 2. 조건입력 후 WKF생성 또는 해당 조건으로 반영된 WKF목록에서 선택 가능) - 조건 입력(1. SQL 생성 / 2. SQL Frag 있으면 바로 생성, 없으면 frag 먼저 자동 생성 후 이어서 SQL 생성(중복 frag 관리 문제는 별도) - 1. 새 WKF 생성시: SQL 목록에 해당 생성된 SQL 추가 / 2. 조건부터 입력시: 관련 SQL의 WKF 목록 제공 / 2-1. 목록이 있어도 새 WKF 생성시: 1.로직 적용 / 2-2. 목록에 있는 WKF 선택시 해당 WKF의 SQL 목록 제공 / 3. 2-2 이후 제공된 SQL 목록이 원하는 조건과 다를 수 있으므로 한번 더 조건 입력시(동일 또는 동일하지 않든) 해당 생성된 SQL이 목록에 추가(단, 목록의 SQL문과 100% 동일한게 있을 경우 생성되지 않고 안내만 제공) / 4. SQL 목록에서 선택 후 등록 버튼 클릭 / 4-1. 기존 내용이 없던 customActivity 였으면 코드편집기에 해당 내용 반영 / 4-2. 기존 내용이 있었을 경우 덮어쓸지 여부 확인 후 선택한 내용으로 진행. / 5. 하단의 해당WKF 열기 클릭 / 5-1. explorer에 해당 WKF를 열어줌. 반영된 내용들이 등록 버튼을 통해 저장되어 있어야함 / 5-2. 이미 WKF 열기로 열어놨을 경우 작업한 내용들이 반영되어 등록 버튼을 통해 저장되어 있어야함 / 6. 제한사항 - 동일 WKF를 다른 유저가 점유하고 있을 경우 WKF 선택 안되고 안내가 필요함. 이유는 XML 편집이 반영되는 부분이 있으므로 동시 점유시 위험할 수 있음.(이 부분을 어떻게 방어해야할지 아이디어 필요함)
