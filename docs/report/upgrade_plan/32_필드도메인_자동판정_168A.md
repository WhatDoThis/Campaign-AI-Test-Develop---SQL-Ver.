# #168-A — 탐색 결과의 frag 결정화 (schema-agnostic)

> frag = SQL 조각이 아니라 **Toolkit 탐색 캐시**.  
> 탐색층(비쌈)은 이미 있음 · 결정층(`_source`)을 채운다.  
> **#174 영향:** 탐색 규칙 `[x]` 유지. EN 사전화(값 전체 1회 번역)는 `#174-3`이 `_source`에 `concept`/`enRefreshedAt`를 추가한다. Generate 바인딩은 `#168-B` 재개.  
> #168-B(Generate `value_not_found`)·#169(조인 병합)는 범위 밖.

## 0. 설계 전제 (신규 탐색기 금지)

| 툴 | 역할 |
|---|---|
| `search_columns` | 컬럼 탐색 |
| `describe_schema` | 속성·link·enum 조회 (+ offset 페이지) |

## 3. `_source` 계약 (탐색 출처)

```json
{
  "_source": {
    "schema": "ns:name",
    "xpath": "@attr",
    "pathFromTarget": "@attr | link/@attr",
    "tier": "enum|distinct|range|…",
    "evidence": "…",
    "discoveredBy": ["search_columns","describe_schema","probe_values"],
    "toolCallCount": 3,
    "schemaFingerprint": "fp…",
    "freshness": "ok|stale|orphaned",
    "refreshedAt": "ISO-Z",
    "truncated": false
  }
}
```

### 스키마 변화 (4단계)

| 상태 | 동작 |
|---|---|
| TTL 유효 | fingerprint **미대조** · 캐시 hit |
| TTL 만료 + fp 일치 | 스냅샷 1회 갱신 |
| fp 불일치 | `_source.freshness=stale` · 사용 보류 후 재탐색 |
| 스키마 소실 | `freshness=orphaned` · **삭제 금지** |

**ACC enum 제약:** `fragmentStatus`에 `stale`/`orphaned` 없음 → Write 매핑  
`stale→deprecated` · `orphaned→revoked` (+ `active=false`). 원문은 `_source.freshness`.  
정식 enum 추가는 스키마 변경 티켓으로 분리.
