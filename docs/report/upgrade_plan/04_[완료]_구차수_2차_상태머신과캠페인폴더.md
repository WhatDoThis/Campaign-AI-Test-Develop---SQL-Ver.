## 6. 구현 상세

### Step 1 — 스키마 확장

- **무엇을**: `<attribute name="isAiFolder" type="boolean" label="AI Studio folder" default="false"/>`
- **어디에**: extension schema under `woo`
- **왜**: UI-3-2 확정안. 운영자가 이름 바꿔도 깨지지 않음

### Step 2 — list API

- **무엇을**: 인증 세션에서 `@isAiFolder = 1` 폴더 select (`@name`,`@label`, id). `lineCount`≤500. Write 경로 없음.
- **왜**: UI-3-1/3

### Step 3 — 상태머신 (클라이언트)

```
NONE → (load folders) → FOLDER_LIST
FOLDER_LIST + select → FOLDER_SELECTED (input enabled, listMode=WKF placeholder)
Back → previous
Reset → NONE
```

- **어디에**: StudioJs  
- **왜**: UI-2-5·6·11·12, UI-4-*

### Step 4 — 입력 게이트

- NONE/FOLDER_LIST: textarea/`생성` disabled + hint div "오른쪽에서 AI 폴더를 선택하세요"
- FOLDER_SELECTED: enable
