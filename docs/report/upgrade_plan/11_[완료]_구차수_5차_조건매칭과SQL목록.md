## 6. 구현 상세

### Step 1 — 키 집합

- plan/used_fragments에서 fragment `name` 또는 `key_column+scope` 집합 A
- 후보 WKF의 최근 registered SQL들의 집합 B
- `J = |A∩B| / |A∪B|` (빈 집합이면 0)
- 응답에 `overlapCount`, `unionCount`, `jaccard` 포함 → UI "조건 n개 중 m개 동일"

### Step 2 — exact

- 동일 plan hash 또는 집합 equality → 최상단

### Step 3 — Register dedup (J-9-3-4)

- sql_query 정규화: 공백/대소문자/세미콜론 트림 규칙 고정 함수
- hash 존재 + 같은 workflow_name → `created:false`, 안내 div

### Step 4 — 목록 규칙

- 폴더 전체 WKF query **금지** (UI-3-5)
- matched 목록 + 항상 "새 WKF"
