## 6. 구현 상세

### Step 1 — 템플릿 준비 (HUMAN+Agent 런북)

- ACC에 `testWooAiWkfTemplate` (가칭) 등록
- `uplus:customActivity` → 환경 계약(`ibankSqlDM`)으로 치환된 템플릿 사용
- Option `testWooAiWkfTemplateName`에 internalName 저장

### Step 2 — Clone API

- **무엇을**: queryDef 템플릿 → deep copy XML → 새 `@internalName`/`@label` → folder link → Write insert → **start 호출 없음**
- **성공 검증**: 상태 중지, 액티비티 수≥템플릿
- **왜**: TPL-6-2

### Step 3 — Lock

- 선택 시 `@lockedBy = currentLogin` (또는 soft-lock 테이블)
- 다른 유저: 목록에서 disabled + 안내 div
- **기술 WF 재시작**: PoC-3 결과 표를 본 문서 배포 런북에 복사

### Step 4 — Open

- PoC-1 PASS: `xtk://open/...pk=`
- FAIL: 정보바에 "콘솔에서 해당 WKF를 여세요" + PK/name + (옵션) extend form 버튼 경로

- Clone API 비활성 Option
- **PoC-3 PASS 롤백**: `@lockedBy` sysFilter 제거 → JS를 soft-lock(`testWooAiWkfLock`) 경로로 핫픽스 전환 → (선택) DB 컬럼은 잔존 허용
