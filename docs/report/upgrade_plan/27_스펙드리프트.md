### 원문 4~5번과의 명시적 차이

1. **입력 게이트**: 원문 “최초 진입 시 입력창 비활성화 → 폴더 지정 후 활성” → 정본 “ST0에서 즉시 입력 활성”.
2. **목록 주연**: 원문 오른쪽은 CAMPAIGN/WKF/SQL이 컨텍스트에 따라 전환 · SQL은 WKF 종속. 정본은 SQL 목록이 **첫 결과 화면**이고 프로그램/캠페인/WKF는 그 다음.
3. **유사도 95%**: 원문(08-11 §5, 08-12 §2) 수치 유지 요구 → 정본 **기각**. containment Top-10 + 동일 배지 (`12_PoC-S`, VLDB). FLOW-5-3의 Jaccard≥0.9는 **dedup 모드 전용**으로 잔존.
4. **새 캠페인 생성**: 원문 §3 “새 캠페인 생성 없음” → 08-12는 분기 A에서 캠페인 생성/선택 허용. **08-12가 우선**(드리프트). UI-3-3는 “목록에서의 무분별 생성 금지”로 재해석하고, ST4 의도적 생성은 허용.
5. **intent create/reuse (#147)**: 08-12 이전 Agent 제안 → SQL-First에서 **폐기**(목록이 분기).
