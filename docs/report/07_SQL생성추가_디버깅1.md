## 내용 정리

증상의 핵심은 `reasoning=0`인데 `completion=8192`라는 점입니다. #83의 사고토큰 차단은 성공했고, 남은 8192는 **모델이 같은 토큰을 반복하다 상한에 부딪힌 것**입니다. Google 개발자 포럼에 "Gemini-2.5-flash repeats tokens until max-tokens reached in structured output"으로 동일 증상이 보고돼 있고, 재현 조건이 JSON 강제 출력입니다. #80에서 Triage의 `response_format`을 뺀 것과 같은 지뢰인데 Pass0에 그대로 남아 있었습니다. 여기에 스모크가 LLM을 한 번도 호출하지 않는 구조라 이 계열이 매번 사용자 입력 시점에 터지고 있습니다.

````
## R-1 (P0) `_chat()` 의 response_format(json_object) 제거

### 대상
`new_ver/js/testWooLlm.js` → `_chat()` (Pass0 `decomposeSlots`, Pass1 `selectPlan` 공용)

- `_buildBody` 에 넘기는 `responseFormat: {type:"json_object"}` 를 **제거**한다.
- 시스템 프롬프트에 이미 `OUTPUT JSON ONLY` 지시가 있으므로 프롬프트는 유지.
- 파싱부는 변경 불필요: `_parseJson` 이 `indexOf("{")` ~ `lastIndexOf("}")` 로 추출한다.

- #80(Triage)과 동일한 처방임을 주석으로 남길 것:

  // (#80 Triage 와 동일 조치) 프롬프트 지시 + _parseJson 추출로 대체한다.
  ```

### 레포 전수 점검
- `response_format` / `responseFormat` 를 grep 하여 **남은 호출 지점을 모두 확인**한다.
- 제거 대상: `_chat`, `explainDedupDiff`(L-1).
- 유지 가능 지점이 있다면 "왜 안전한지"를 주석으로 남기고 로그에 근거를 남긴다.

## R-3 (P1) finish_reason="length" 진단 강화

### 배경
````
